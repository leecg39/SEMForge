# Site Audit AI 기능 범위

## P2: 근거 기반 이슈 우선순위 요약

- 입력은 선택한 `runId`의 저장된 이슈와 지표로 제한한다.
- 출력의 각 권고는 원본 이슈 ID/제목/영향 URL 수를 참조해야 한다.
- AI 제공자가 구성되지 않아도 프로젝트 목록과 상세 진단의 모든 핵심 기능은 동작해야 한다.
- 다른 실행의 요약을 재사용하지 않고 `runId` 단위로 버전 관리한다.

이번 빌드에서는 핵심 프로젝트 허브와 실제 크롤 실행을 우선하며, AI 제공자 설정이 없는 환경에서는 요약 생성 CTA를 노출하지 않는다. 가짜 AI 결과나 고정 문구를 만들지 않는다.

# Semrush Organic Research 개요 — 행동 명세 (인터랙션 스윕 결과)

## 스크롤

- **sticky/fixed 없음.** 헤더·필터바·페이지 탭바는 스크롤과 함께 위로 흘러감. 스크롤 트리거 애니메이션·IntersectionObserver 진입 애니메이션 없음(정적 렌더).
- 페이지 자체 스크롤(window). 내부 스크롤 컨테이너 없음.

## 페이지 탭바 (개요/포지션/포지션 변경/경쟁자/주제/서브도메인)

- `button[role="tab"]`, 높이 40px, 폰트 13.33px/500, 색 `rgba(1,5,0,0.898)`.
- 탭 간격: margin `0 16px 0 32px` 패턴(첫 탭 좌측 0). 탭리스트 하단 `1px solid rgba(0,12,8,0.16)` 전폭 보더.
- **활성 표시**: 탭의 `::after` — 높이 **3px**, 배경 `rgba(0,40,230,0.42)`, `position:absolute; bottom:-1px`, 탭 전폭.
- 클릭 시 해당 서브페이지로 이동(개요 화면에서는 개요만 활성). 클론에서는 개요 외 탭은 시각적 재현 + 비활성 이동.

## 세그먼트 컨트롤 (joined button group) — 공통 패턴

사용처: 상위 키워드(모든 포지션/유기적/SERP 구성 요소), 포지션 변동(신규/누락/상승/하락), SERP 변동(신규/누락), 필터바 DB 탭(KR/US/UK).

- 버튼 높이 28px, 폰트 14px/400, 흰 배경, 보더 `1px solid rgba(0,12,8,0.16)`, 인접 보더 겹침(-1px margin), 첫/끝 라운드 `6px 0 0 6px` / `0 6px 6px 0`.
- **선택 상태**: 배경 `rgba(0,81,255,0.04)`, 보더 `1px solid rgba(0,40,230,0.42)` (z-index로 인접 위 표시), 글자색 `rgb(0,0,0)`.
- 트리거: 클릭 → 즉시 콘텐츠 교체(트랜지션 없음). DB 탭은 데이터 재조회.
- DB 탭 내부: 국기(16px) + 국가코드 + 우측 회색 카운트 숫자, 뒤에 `…` 오버플로 버튼.

## 기간 필 (1개월/6개월/1년/2년/항상) — 추세·SERP 트렌드 카드 공통

- 텍스트 버튼(aria-selected), 폰트 13.33px/500, 색 `rgba(1,5,0,0.898)`, 배경 없음, 간격 ≈16px.
- **활성 표시**: `::after` 높이 3px, 배경 `rgba(0,40,230,0.42)` (페이지 탭과 동일 패턴). 기본 선택: **항상**.
- 클릭 → 차트 x축 범위 즉시 변경.

## 범례 체크박스 (자연 키워드 추세)

- 16px 컬러 체크박스(체크 시 해당 색 채움+흰 체크, 해제 시 아웃라인) + 라벨 텍스트. 클릭 → 해당 시리즈 토글(즉시).
- 색 (스택 순서 하→상, computed):
  - 상위 3개: `oklch(0.82 0.18 80)` (주황)
  - 4-10: `oklch(0.46 0.141 280.7)` (진인디고)
  - 11-20: `oklch(0.58 0.168 278.2)` (인디고)
  - 21-50: `oklch(0.74 0.117 274.1)` (중간 블루바이올렛)
  - 51-100: `oklch(0.82 0.088 272.1)` (연블루바이올렛)
  - SERP 구성 요소: `oklch(0.82 0.19 143)` (초록) — 기본 체크
- 우측에 `메모` 토글(말풍선 아이콘 + 캐럿) — 클론에서는 시각 재현만.

## SERP 트렌드 라인 색

- AI 개요: `oklch(0.82 0.18 80)` / 추천 동영상: `oklch(0.74 0.225 330)` / 관련 질문: `oklch(0.58 0.168 278.2)`
- `기타 구성 요소` 셀렉트 드롭다운 1개.

## 차트 공통 (Highcharts풍 스타일)

- 그리드라인: `rgba(0,21,16,0.07)` 1px 수평선. 축선: `rgb(214,216,215)`. 축 라벨: 11~12px 회색.
- 추세 차트: 스택 세로 막대, 막대 폭 ≈6px, 주 단위(53pt/년). 호버 시 십자선+툴팁.
- KPI 스파크라인: ① 막대형(연블루바이올렛 `oklch(0.82 0.088 272.1)`, 마지막 막대만 `oklch(0.58 0.168 278.2)`) ② 라인+영역형(`rgb(102,107,219)` 선, 연한 동일색 영역, 끝점 도트, 기준선 `rgb(224,225,233)`)
- 버블 차트(경쟁 포지셔닝): 버블 색 6종 `oklch(0.58 0.168 278.2)`, `oklch(0.82 0.15 170)`, `oklch(0.74 0.17 303)`, `oklch(0.82 0.18 80)`, `oklch(0.74 0.19 22)`, `oklch(0.82 0.088 272.1)` — 흰 스트로크, 반투명 채움.

## 의도별 키워드

- 카드 상단 가로 분포 바(높이 16px): 세그먼트별 색, 양끝 radius 2px. 범례 도트 12px 원형.
- 의도 색: 정보제공(I) `oklch(0.74 0.117 274.1)`, 탐색(N) `oklch(0.74 0.17 303)` (+ 상업 C/거래 T 컬러는 데이터 존재 시 동일 팔레트 계열).
- 행: 의도 도트+라벨 링크, 우측 % 링크(파랑), 키워드 수, 트래픽 %.

## 테이블 (상위 키워드/페이지/서브도메인/경쟁자 공통)

- 헤더: 12px 회색 `rgba(0,3,0,0.584)`, 정렬 아이콘(Sortable), 하단 보더.
- 행 높이 ≈37px, 하단 보더 `1px solid rgba(0,21,16,0.07)` 계열, **hover: 연파랑 틴트(rgba(0,81,255,0.04) 계열)**.
- 키워드/URL 셀: 파란 링크 `rgb(35,95,226)`, 밑줄 없음(hover 시 밑줄), 뒤에 SERP 미리보기 아이콘(회색 사각 아이콘, hover 시 표시).
- SF 열: 점선 밑줄 숫자(회색 `rgba(0,3,0,0.584)`) — hover 팝오버(클론: 툴팁).
- 수치 열 우측 정렬. `< 0.01` 형태 표기 유지.

## 카드 공통 셸

- 흰 배경, 라운드 6px, 보더 `1px solid rgba(0,21,16,0.07)` + 미세 그림자, 패딩 16px, 제목 16px/600 `rgba(1,5,0,0.898)`.
- 하단 CTA 버튼(모두 보기): **검정 배경 `rgb(26,30,26)`**, 글자 `rgba(254,255,255,0.95)` 14px, 높이 28px, radius 6px, 패딩 좌우 12px. hover: 미세 밝기 변화(≈`rgb(40,44,40)`).

## 빈 상태 (포지션 변동 카드 2종)

- 중앙 정렬: 일러스트(원본은 정적 SVG 80px — 클론은 자체 제작 미니 SVG) + "결과가 없습니다" 14px/600 + "필터를 변경해 보세요." 12px 회색.

## 링크·버튼 공통

- 본문 링크: `rgb(35,95,226)`, hover 밑줄. 보조 링크(사용자 매뉴얼 등): 파랑 12px + 16px 아이콘.
- PDF로 내보내기: 아웃라인 버튼(흰 배경, 회색 보더 `rgba(0,12,8,0.16)`, radius 6px, 높이 28px, 좌측 내보내기 아이콘).
- 필터바 드롭다운 트리거(장치/날짜/통화): 라벨 회색 12px + 값 파란 링크식 텍스트 + 파란 캐럿. 날짜 값은 `2026년 7월 31일` 형식.

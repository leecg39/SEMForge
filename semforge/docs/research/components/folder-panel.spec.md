## States & Behaviors

### 필터 바 조건부 노출
폴더가 **1개면 필터 바가 렌더되지 않는다**. 2개 이상일 때 검색·소유권·태그·테이블 보기 스위치가 나타난다.
(이전 세션에서 폴더 2개 상태로 실측 확인)

### kebab 메뉴
`공유` / `핀 고정` / `태그` / `설정` / ─구분선─ / `삭제`

### 도메인 없는 폴더
지표 스트립 대신 `+ 웹사이트 추가` 버튼과 안내 문구
"웹사이트를 추가하여 순위, 키워드 백링크를 모니터링하고, 문제를 해결하고, LLM 전반에서의 가시성을 높여보세요."

### 성공 피드백
없음. 목록 즉시 갱신이 유일한 피드백이며 토스트·되돌리기·휴지통 UI 는 존재하지 않는다.

## Responsive Behavior
- **1440px:** 8열 지표 스트립 한 줄
- **768px:** 지표 가로 스크롤
- **390px:** 버튼 전체폭 세로 스택, 폴더 행 내부 가로 스크롤

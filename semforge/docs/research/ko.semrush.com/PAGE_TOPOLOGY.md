## z-index / 레이어

- `snav-sidebar` 호스트: `position: fixed` (렌더 시 정적 열로 배치, 폭 77px)
- 헤더: `position: relative`, 문서 흐름 유지 (sticky 아님 — 이 페이지는 스크롤이 없음)
- 도움말 FAB: 뷰포트 우하단 고정
- 모달/드롭다운: 헤더보다 위

## 의존 관계

- 콘텐츠 열의 x 좌표는 레일 폭(77px)에 종속된다. 레일이 숨는 뷰포트에서는 x=32로 이동한다.
- 폴더 섹션의 필터 바는 폴더 개수에 종속된다 (1개면 숨김, 2개 이상이면 노출 — 이전 세션에서 실측 확인).
- 폴더 행의 지표 스트립은 폴더에 도메인이 연결된 경우에만 렌더된다. 도메인이 없으면 `웹사이트 추가` 버튼과 안내 문구로 대체된다.

## Implemented scope

- Workspace-scoped multiple Google Search Console connections with user-provided labels.
- OAuth authorization URL with exact readonly scope `https://www.googleapis.com/auth/webmasters.readonly`, `access_type=offline`, and consent/account selection prompt.
- 32-byte random client-visible OAuth state with SHA-256-only DB storage.
- State binding to user, workspace, return path, provider, 10-minute expiry, and one-use CAS consumption.
- Authorization code exchange, encrypted access/refresh tokens using AES-GCM AAD `workspace:{workspaceId}:gsc:{connectionId}:{access-token|refresh-token}`.
- Refresh-token preservation when Google omits `refresh_token` on refresh, and rotation when Google returns a replacement.
- Search Console `sites.list` REST adapter and OAuth revoke adapter.
- Property binding by site and connection with workspace composite boundaries.
- API routes under `/api/v1/integrations/gsc/*` using API v1 envelope and real auth guard runtime wiring.

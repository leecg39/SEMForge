# 목표 정의

## 프로젝트 목표 (Project Goal)

> `semrush-clone` 이 `https://ko.semrush.com/` 과 동등하게 **오류 없이 정상 작동**하도록 만든다.

"정상 작동"의 조작적 정의 — 아래 4가지를 모두 만족한 상태.

| # | 완료 조건 | 측정 방법 |
|---|---|---|
| C1 | 전 라우트 HTTP 200, 깨진 링크·누락 자산 0 | `node scripts/audit-site.mjs` |
| C2 | 브라우저 콘솔 오류·실패 요청 0 | 템플릿 계열별 대표 페이지 CDP 스윕 |
| C3 | 화면에 보이는 컨트롤이 실제로 동작 (죽은 버튼 없음) | 인터랙션 스윕 |
| C4 | 공개 사이트 → 로그인 → 앱 CRUD 가 하나로 이어짐 | `scripts/verify-crud.mjs` + 수동 흐름 |

## 마일스톤

| ID | 마일스톤 | 완료 조건 |
|---|---|---|
| M1 | 무결성 확보 | C1 + C2 달성 |
| M2 | 인터랙션 완결 | C3 달성 (죽은 컨트롤 0) |
| M3 | 앱 연결 | C4 달성 (공개↔인증↔CRUD 단일 흐름) |
| M4 | 한국어 로케일 | ko.semrush.com 기준 화면 언어 대응 |

## Phase 목표

- **Phase 0** — 현황 진단: 실제 결함 목록 확정 (추측 배제)
- **Phase 1** — 인증 연결: 정적 로그인/가입 폼을 실제 세션 인증에 연결
- **Phase 2** — 앱 라우트 연결: 비로그인 리다이렉트 + 로그인 시 실제 CRUD 화면
- **Phase 3** — 공개 사이트 결함: 가격 토글 등 반응하지 않는 컨트롤 수정
- **Phase 4** — 한국어 로케일 (범위 협의 필요)

## 범위 밖 (Non-goals)

- Semrush의 실제 SEO 데이터·분석 결과 재현 (외부 데이터 의존)
- 상표·로고·원문 마케팅 카피의 그대로 복제 (중립 플레이스홀더 유지)
- 결제·구독 실제 처리
